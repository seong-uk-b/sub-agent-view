# 캐릭터 스프라이트 출처

- 원작: JIK-A-4, "MetroCity – Free Topdown Character Pack" (https://jik-a-4.itch.io/metrocity-free-topdown-character-pack), CC0 1.0.
- 시트 구성(112×96, 16×32 프레임 7열×3행)은 pixel-agents(MIT, https://github.com/pablodelucca/pixel-agents)의 `webview-ui/public/assets/characters/char_N.png`를 그대로 사용.
  - 행: 0 정면 / 1 뒷모습 / 2 오른쪽 (왼쪽은 좌우 반전)
  - 열: 0 서 있기 / 1–2 걷기 / 3–4 타이핑 / 5–6 읽기
